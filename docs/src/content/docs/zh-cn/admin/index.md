本手册写给搭建 homeserver 的人：为自己、为家人，或者作为替朋友保存备份的
第二个节点。读者需要熟悉终端。使用节点的人只需要[用户手册](../user/)。

:::caution[0.1.0 版本]
homeserver 处于实验阶段。不同版本之间数据格式仍可能变化，请保留导出和加密
副本。自动更新和网页应用尚未提供。
:::

## 你运行的是什么

一个节点就是**一个程序 `hs` 加一个数据目录**。不需要配置数据库服务器、
容器或反向代理。`hs` 运行节点（`hs ctl serve`）、管理节点（`hs ctl …`，
或指向同一程序的链接 `hsctl`），也使用节点（`hs ls`、`hs search` 等）。

## 要求

- Linux（x86_64 或 aarch64）或 macOS。macOS 适合试用。
- 很少的内存和 CPU：设计目标是一个核心、1 GB 内存服务十口之家。
- 足够存放你的数据和缩略图的磁盘。
- 若要从家外访问：路由器支持 NAT-PMP 或 PCP，或者手动转发端口。两者都
  没有时，节点在局域网内可用。公网 HTTPS 域名是可选的，需要你自己的反向
  代理。

## 阅读顺序

1. [安装](install/) `hs`。
2. 创建节点并[运行](running/)。
3. 给人和应用发[令牌](access/)。
4. 设置[备份](backups/)，并妥善保管恢复码。
5. 可选：让其他应用通过节点[登录](sign-in/)。

[配置](configuration/)和[故障排除](troubleshooting/)涵盖其余内容。
