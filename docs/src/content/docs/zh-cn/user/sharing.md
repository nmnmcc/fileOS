---
title: 分享
description: 与其他 homeserver 上的人共享空间。
---

分享以空间为单位。每个人保留自己的 homeserver；空间由其中一个节点排定顺序，
称为**主节点**，其他人关注它。每个人都在自己的节点上读写，修改会自动传到
其他人那里。

## 分享你保管的空间

如果空间还不存在，先创建，并查看它的 ID：

```sh
hs space create "家庭相册"
hs space list
```

按地址添加对方的节点，你的节点会询问它是谁：

```sh
hs space member add "家庭相册" --url hs.friend.example --role writer
```

角色：

| 角色     | 可以                               |
| -------- | ---------------------------------- |
| `reader` | 读取                               |
| `writer` | 读取和写入（默认）                 |
| `owner`  | 还可以添加、移除成员，以及移交空间 |

把空间 ID 和你节点的地址发给对方。

## 加入别人分享给你的空间

所有者添加了你的节点之后：

```sh
hs space join --home hs.owner.example 4b1d…
```

这个空间随即出现在 `hs space list` 和搜索中，新的修改会实时推送到你的
节点。想立即同步，运行 `hs space sync 空间`。

## 查看和调整空间成员

```sh
hs space show "家庭相册"
hs space member remove "家庭相册" 节点密钥
```

`hs space show` 列出每个成员的节点密钥、所有者和角色。

移除成员后，新的修改不再发给对方。对方已有的内容仍留在对方那里。

## 把空间移到另一个节点

如果主节点要停用，所有者可以让另一个成员的节点成为主节点。因为每个成员都
已有日志，所以不需要复制任何东西：

```sh
hs space handover "家庭相册" 节点密钥
```

:::note[0.1.0 版本]
共享空间还没有端到端加密。修改经 TLS 传输，由各节点签名，并以明文保存在
每个成员的节点上。只与你信任其 homeserver 的人分享。
:::
