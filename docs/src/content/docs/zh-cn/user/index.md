homeserver 把你的笔记、文件、照片、联系人、日历和密码保存在一台属于你、
或属于你信任的人的机器上。本手册写给使用它的人。搭建节点本身见
[管理手册](../admin/)。

:::note[0.1.0 版本]
目前还没有网页应用。你通过 `hs` 命令行，以及你已经在用的应用（通讯录、
日历、Bitwarden 和 AI 助手）来使用 homeserver。
:::

## 五个概念

**身份。** 你是一把密钥，而不是某台服务器上的账号。你的身份 ID 由这把密钥
派生，是一串字母和数字；homeserver 换机器、换地址，它都不变。
`hs identity` 以 DID 文档的形式显示它。

**空间。** 空间是作为整体保存和分享的集合：你的私人空间、家庭空间、共享
相册。每个空间有成员，并由一个节点负责排定它的顺序。

**条目。** 空间里的一切都是条目，有类型和 ID，写作 `类型/ID`：
`note/shopping`、`contact/ada`、`event/dentist`、`file/…`。大多数条目是
JSON；文件保留原始字节。

**历史。** 每次修改都签名后追加到空间的日志里。搜索、时间线和地点都由日志
生成，随时可以重建。

**授权。** 每个应用和每个人都用令牌访问你的数据，每个令牌都是一项你能列出
和撤销的授权。没有你看不到的访问。
