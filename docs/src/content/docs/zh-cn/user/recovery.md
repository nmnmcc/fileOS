---
title: 恢复码
description: 妥善保管恢复码，也可以把它分给朋友保管。
---

创建 homeserver 时，它会打印一次**恢复码**。恢复码是你身份的钥匙，也能
解密你的备份。它不保存在任何地方，节点上没有，别处也没有。

只凭恢复码，就能从备份中恢复出一个新节点。没有它，任何人都读不了加密备份。

## 妥善保管

- 写在纸上，和重要证件放在一起。
- 不要只保存在 homeserver 上，也不要只保存在本身就放在 homeserver 上的
  密码管理器里。
- 拿到恢复码的人就能恢复你的数据。像对待家门钥匙一样对待它。

## 分给朋友保管

除了把一份副本放在一个地方，你还可以把恢复码拆成若干份，凑够其中几份就能
还原。例如拆成五份，任意三份即可：

```sh
hs ctl recovery split --threshold 3 --count 5
```

`hs` 询问恢复码，然后打印五行以 `hs-share-` 开头的内容。每位信任的人给
一份。单独一两份不会泄露任何信息。

要找回恢复码，收集足够的份数，每行一份：

```sh
hs ctl recovery combine < shares.txt
```

如果份数不够，或某一份损坏、来自另一个恢复码，`hs` 会明确指出，而不会打印
错误的恢复码。

用恢复码恢复节点见[备份与恢复](../../admin/backups/)。
