title: 查找
description: 搜索、时间线、地点、关联和实时变化。
---

这些命令在你能读取的所有空间里查找。

## 搜索

```sh
hs search 公园
hs search park
```

搜索标题和正文，按相关度排序。中文、日文和韩文按两个字一组建立索引，所以
`公园` 能找到 `人民公园`。

## 时间线

```sh
hs timeline
hs timeline --before 2024-06-01 --limit 20
```

带有 `time` 的条目（有 EXIF 的照片、笔记、日程）按时间倒序列出。
`--before` 接受一个 UTC 日期。

## 地点

```sh
hs near 31.23 121.47            # 1 公里以内
hs near 31.23 121.47 --km 5
```

先纬度、后经度。带 GPS 信息的照片和带 `place` 的条目会被找到。

## 关联

```sh
hs related family person/mom
```

列出关联到某个条目的内容，以及它关联到的内容：和某个人有关的一切、某个
地点的一切、某个项目里的一切。

## 实时变化

```sh
hs watch
```

你能读取的任何空间每发生一次变化，就打印一行，直到按 Ctrl-C。可以用来
看朋友的新照片到达，也可以用在脚本里。
